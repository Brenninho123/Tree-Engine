# 🌳 Tree Engine

A specialized, high-performance game engine built from the ground up using **Haxe** and **Lime**. Designed for flexibility, clean node structures, and cross-platform compatibility.

## 🚀 Features (Work in Progress)
- **Node-Based Scene Graph:** Elegant parent-child object management ("Tree" architecture).
- **Cross-Platform Target:** Compile natively to PC, Web (HTML5), and Mobile (Android/iOS).
- **Custom Shaders & FX:** Optimized GLSL shader support seamlessly applied to UI, gameplay cameras, and `camHUD`.
- **Modular HUD System:** Highly customizable ranking and score management built natively.

## 🛠️ Requirements & Setup
To compile this engine, you need to have **Haxe** and **Lime** installed.

1. Install Haxe (4.3.0+ recommended)
2. Setup Lime via terminal:

   haxelib install lime
   haxelib run lime setup
